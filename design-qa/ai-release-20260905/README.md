# 同频 AI 0.1.33 发布前验收

日期：2026-09-05。本记录覆盖后续补齐的功能；早期 `../ai-api-20260905/README.md` 是前一阶段快照，不代表当前完成范围。

## 浏览器实测

- 独立临时数据库、4329 API、5189 页面；仅使用 `tongpin.test` 合成账号和明确标注的假上游，不接触正式成员数据或服务商余额。
- 管理员通过真实表单读取模型、保存 Responses 配置、启用独立图片能力并分配 100,000 额度；成员通过真实登录使用。
- 首次进入引导取名“小频”、选择“高效行动派”、填写自定义风格和显式偏好，确认后服务器保存。刷新和在另一浏览器重新登录后，名称、性格和偏好仍保留，没有重复首次引导。
- 创建空项目“客户提案验收”，保存项目要求，再在项目内创建“方案与演示文稿”。项目、对话、附件与生成成果在刷新和另一浏览器登录后均恢复。
- 上传合成 TXT，页面实际提取 97 个字符。选择生成 PPT，经过后端额度预留、结构化返回后得到 3 页成果。
- Chrome 点击“下载 PPTX”确实产生 `客户提案验收.pptx`。`unzip -t` 全部通过，包含 3 个幻灯片 XML、备注和原生可编辑中文文本框，不是图片伪装的 PPT。
- 文字生成图片后，成员通过鉴权接口加载成果；Chrome 下载得到有效 PNG。测试上游只返回 1×1 合成图片，因此该项验证传输、权限、保存和下载链路，不评价真实模型画质。
- Token 详情显示输入 24、输出 48；图片单列折算 1,200 额度；累计 1,272，可用 98,728，预留 0。文字 Token 与图片折算没有混称为模型实际 Token。
- IAB 未捕获到下载事件，未以此冒充成功；改用标准 Chrome 下载并检查磁盘产物。Chrome 日志只有已有钱包扩展的警告，没有同频页面自身错误。
- 发现并修复成果预览 981–1100px 的网格换行问题，以及删除对话、切账号、离开 AI 与付费请求之间的竞态。

## 自动化与真实运行时

最终 `npm run build`：90 个测试文件、709 项测试全部通过；前端/Node 构建、Cloudflare 类型检查、Wrangler dry-run 和 CJS 语法检查通过。发布版本为 0.1.33。

回归覆盖账号隔离、管理员权限、零额度拒绝、并发额度预留、请求幂等、失败结算、未知结果读取而不重复付费、持久化冲突与版本校验、Persona 清除/修改、文档解析和真正的 PPTX 内容。

Cloudflare 测试实际启动 workerd 和 SQLite Durable Object，覆盖注册/审批/登录、Provider 加密存储、可信域名限制、禁止跟随重定向、工作区/专属 AI/资产保存与跨账号拒绝。仅上游模型传输被注入合成响应。

## 0.1.34 平台打包校验

- 0.1.33 的跨平台 CI 质量门通过，但 Mac 通用包受到 PDF 库的 Node 可选 canvas 原生依赖影响，Windows 暴露了 POSIX 权限测试假设及测试结束未释放 SQLite 句柄。该版本没有正式发布；未改写原 tag，后续发布使用 0.1.34。
- PDF/PPT/DOCX 依赖改为 Vite 构建依赖，保留浏览器功能，不把不需要的 Node 原生组件装入 Electron。真实本地 macOS universal DMG/ZIP 打包通过，二进制同时含 x86_64 与 arm64；最终 asar 必需入口、PDF worker、许可证、生产 API/更新 URL 与无 native canvas 校验通过。
- 增加统一、幂等的 Node 关闭流程，等待运行中的 HTTP/付费请求完成结算后再关闭 SQLite；所有测试实例（含重新打开的实例）均正确清理。Windows 仅检查其支持的文件权限位，不伪称 POSIX 位可验证 Windows ACL；Unix 仍严格检查 0600。
- 0.1.34 本地最终 `npm run build` 92 个文件、716 项测试通过；两端类型检查、前后端构建、Cloudflare dry-run、macOS 本地完整包校验均通过。跨平台 CI 和正式远端激活另行验收。

## 必须明确的边界

- 没有取得完整真实服务商密钥，因此未验证用户购买的上游模型、真实图片质量或真实联网搜索。正式管理员需在 AI 管理内输入密钥、测试连接、选择模型、分配成员额度；截图中的掩码不是可用密钥。
- 回复是服务器聚合后在界面逐字显示，不是浏览器实时接收上游 Token。停止等待不保证服务商停止计费；相同请求可读回已有结果，不自动重复收费调用。
- 长期记忆保存成员明确确认的助手名、性格和偏好，不擅自从聊天抽取敏感信息；项目资料与聊天历史独立保存。
- 文档支持文字提取，不含扫描 PDF OCR。图片入口是文字生成，不宣称已经实现多模态图片理解。联网搜索需兼容的 Responses 原生搜索能力。
- Skill 市场为审核过的文本工作指引；导入 SKILL.md 仅作为文档，不运行任意脚本，不等同开放插件执行沙箱。
- PPT 使用严格结构化数据生成原生文字与备注。目前 `image-size` 传递依赖仍有两个高危审计条目且没有修复版本；当前 PPT 路径不接受图片、媒体、URL 或二进制输入，回归明确禁止调用相关解析函数。详见 `AI_DOCUMENT_LIBRARY_NOTICES.md`。
- 生产发布、远端包校验、Windows 更新 manifest 激活及 macOS 手动分发另行记录；本文件本身不是已部署的凭证。
