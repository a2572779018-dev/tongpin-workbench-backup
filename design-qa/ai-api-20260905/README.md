# 同频 AI 自定义 API 与成员额度验收

日期：2026-09-05。此记录只证明本地实现和隔离测试，不代表正式发布或真实服务商接入成功。

这是当天早期阶段的历史快照。后续已补齐持久化、专属 AI、文档、PPT 与图片等能力，当前发布前验收见 `../ai-release-20260905/README.md`。

## 已完成

- 管理员专属“AI 管理”：自定义 HTTPS Base URL、Responses / Chat Completions 协议、服务端加密密钥、快速和深度模型、输出上限。
- 首次接入可先填写地址和密钥获取模型，再选模型保存；不要求先保存不存在的模型。保存后密钥不返回页面，更换域名必须重新输入密钥。
- 真实成员列表、累计 Token 限额、管理员设置/追加、自己的输入输出用量明细。默认 0，不自动重置。
- 成员经过真实登录权限校验后调用后端。后端预留额度、结算真实用量、幂等去重，并处理断线及不确定用量。成员不能自加额度或读取管理员密钥。
- Responses 接收上游 SSE 或 JSON，服务端聚合完整回复，页面以打字效果显示；并非浏览器直接连接上游或实时接收 Token。
- 前端的停止等待不会承诺取消上游或退款。网络中断仅重新获取同一请求；服务商已确定终止的请求不会显示无效重试按钮。
- 图片、PPT、上传及联网搜索尚未接入，入口不冒充可用功能。项目与对话仍沿用现有按用户隔离的内存会话，不承诺刷新后或跨设备保存。

## 本地与正式环境边界

- 本地 5173 页面已经恢复，新版 Node API 在 4318 运行。沿用原预览数据文件 `/tmp/tongpin-ai-preview.ecbeZQ/database.json`，没有替换账号、密码、角色或会话密钥。
- 此预览数据库只有原有本地管理员和预览成员，没有用户的 Outlook 正式管理员账号。禁止通过创建同名本地账号假装接通正式账号系统。
- 正式桌面应用仍指向现有云端服务。本次未推送代码、未部署 Worker、未打包/发布桌面更新、未修改线上数据。
- 正式验证还需要发布前后端，以及由管理员自己在管理页面输入完整密钥、读取模型、设置成员限额，然后登录真实成员测试。截图中的掩码密钥不能用于验证。
- Cloudflare 运行时通过公共 DNS 校验拒绝私网目标且禁止重定向，但不能像 Node 一样固定 DNS 解析到 TLS 连接。正式部署前应采用可信域名白名单或受控出站代理进一步降低 DNS 重绑定风险。
- 本地 API 的数据库与加密主密钥文件应一起安全备份，不能上传仓库；已补充 gitignore 规则。

## 管理员操作顺序

1. 登录对应环境的管理员，在“AI 管理”填写供应商 API 地址和密钥。
2. 按供应商文档选择协议，点击“测试连接 / 获取模型”，选择快速/深度模型 ID，保存并启用。模型列表不可用时可以手动输入文档给出的模型 ID。
3. 在成员列表设置 Token 总限额，再用该成员账号进入“同频 AI”发送测试消息。
4. 点击左下角头像核对 Token 明细。这里限制的是输入加输出 Token，不是供应商账户的美元余额。
