### Mac 的验收边界

截图的临时安全存储错误不等于客户图文件损坏。安装版本、适配器及金库代码已只读比对；现有日志没有证明是钥匙串被拒、锁定或签名变化中的哪一种。Electron 的异步密钥初始化可能缓存失败状态，所以完整退出后重开与仅重载页面不同。[Electron safeStorage 文档](https://www.electronjs.org/docs/latest/api/safe-storage)、[匹配安装版本的实现](https://github.com/electron/electron/blob/v43.2.0/shell/browser/api/electron_api_safe_storage.cc)。

未清空本地目录、未生成新密钥覆盖旧密文、未加入明文降级。模拟恢复只验证应用契约，不能代替这台 Mac 对原文件成功解密。详见 [Mac 排查记录](/Users/sam/Documents/ChatGPT/个人/tongpin-workbench-git/docs/MACOS_SAFE_STORAGE_DIAGNOSIS_2026-09-07.md)。

## 本轮流程验收

截图均为本轮浏览器实际捕获并打开检查的文件。首屏取名/未开通截图早于最终系统光标修正，最终工作区与后续截图已核对无自绘光标。页面截图只能说明可见状态；权限、持久化与性能另有接口/代码测试。

### 1. 未开通账号进入 AI — 通过

清楚显示未开通、当前账号与重新检查入口；不显示取名流程，不预加载个人工作区。入口单测确认此路径只请求状态。服务端同时拒绝人设、工作区和生成请求，不能靠绕过界面获得权限。

明确标注“AI 的名字”，避免误填成员姓名。依次取名、选性格、确认偏好；没有在保存成功前声称已长期记住。初始化过程中不挂载隐藏工作区。

## 性能和测试证据

- 最终 `npm test`：**96 个文件、748 项通过**。
- `npm run typecheck`、`npm run typecheck:cloudflare`、`npm run build:web`、`npm run build:api`、`git diff --check` 通过。
- Cloudflare 打包 dry-run 通过；**dry-run 不是发布**。
- 独立复查：入口、播放、权限、人设、工作区及 Cloudflare 路由相关 **127 项**通过，没有发现新增阻断性回归。
- Mac 安全存储/金库/身份绑定专项 **73 项**通过；包括失败时原密文不变、不创建新密钥覆盖、模拟恢复后可读。未访问真实钥匙串或客户内容。
- 本地 CPU 6 倍限速采样：1,402 字模拟回复打字区间记录一次 64ms 长任务；160 条长历史入口区间记录 83ms 与 53ms 长任务。本次没有观察到秒级冻结，但这不是低配 Windows 实测，也不是帧率保证。
- 合成服务端渲染 1,000 条历史：旧实现挂载 1,000 条、HTML 677,758 字节、中位约 14.04ms；新实现挂载 40 条、39,270 字节、中位约 4.1ms。该数据用于解释渲染规模，不等于桌面端启动时间。
- 浏览器限速和临时性能观察器已恢复/移除。测试数据位于专用临时目录，未动生产数据。

## 仍未完成的验证与发布条件

1. **Mac 原数据恢复**：这台 Mac 完整重启同频后成功读取同一份原密文，才能宣布问题 1 修复完成。不能用测试夹具替代。
2. **低配 Windows 实机**：至少验证首次进入、长回答输入、滚动和切换会话，记录长任务/内存；本轮只做了本地人工限速。
3. **真实模型与账单**：管理员配置 → 给成员额度 → 成员真实对话 → 扣额/耗尽阻断。本轮未调用真实 API，不能据此宣布模型、PPT 或图片生产链路全部验收完成。
4. **真实服务端流式输出**：当前仍是上游完整响应到达后，前端播放打字效果；不是模型边生成边传输的 SSE。UI 卡顿与模型响应等待是两个问题，不能混为一谈。
5. **发布顺序**：先更新后端，核对 status 的 `accessGranted` 及已/未开通账号，再发布客户端。新客户端遇到旧后端缺失字段会安全拒绝进入；不能客户端先行，也不能单独回滚后端。旧客户端在新后端下，未开通会被 403 拦截，但仍显示旧通用错误。
6. **已有发布习惯不变**：远端完整校验包后才能切换更新 manifest；unsigned Mac 包仍手工安装；本轮未上传包、未切换 Windows 更新源、未修改已安装应用。
