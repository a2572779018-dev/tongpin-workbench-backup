# AI 视频功能复核（2026-09-21）

## 结论

总验收清单现为 35 项（原 27 + 本轮 6 + 最后 2 项）。本文详细复核视频相关项，并对本轮新增的第 4/5 项给出实现证据。这不是“全绿”报告：已区分自动测试通过、仅代码复核、以及未进行真实付费/桌面手工验收的受限能力。

本轮已把视频紧凑输入区恢复为“明确选模型 + 一次发送”：用户点击右下角发送后，客户端先调用真实对话规划，必须取得服务端签发的 `planRequestId`，然后在同一次明确发送中立即提交该方案。页面不再显示“让同频 AI 整理”或第二个“确认生成”按钮。

模型选择不是客户端任意传值。成员端可见列表和规划/生成授权均由服务端计算：`VIDEO_MODELS` 中本地已接入模型 ∩ 当前业务档位视频供应商已验证 `availableModels`。规划保存绑定后的模型，提交时再校验完整参数、参考图指纹、配额、租户和幂等。

## 原视频项 1–7

1. **模型下拉：已实现。** `AiVideoComposer.tsx` 从成员视频设置读取当前档位的已授权模型，显示名称，并按选中模型即时限制清晰度、时长和参考图数。
2. **一次发送：已实现。** `AiVideoComposer.submit()` 顺序执行 `onPlan` 和 `onSubmit`；`ChatWorkspace.tsx` 右下角发送是唯一生成触发点，忙碌期禁用并显示加载状态。
3. **真实上下文规划：已实现。** `TongpinAIPage.planTool()` 把当前对话、项目指令、显式模型/时长/清晰度/画幅和参考图指纹交给 `/api/ai/preflight` 与 `/api/ai/chat`，不是客户端字符串拼接假规划。
4. **服务端确认与付费边界：已保留。** 没有 `planRequestId` 时禁止上传参考图、持久化生成卡片或 POST 视频；必须先保存工作区，再做唯一一次生成 POST。服务端在同一事务中预留配额、占用工具方案、写入任务；请求 ID 重放返回原任务，不会二次调供应商。
5. **时长契约：本轮未改 SD2.5。** `shared/aiVideoModels.ts` 中 SD2.5 仍是 30 秒，按用户明确要求不修改。播放器会显示请求时长和实际媒体时长差异，且不自动重新生成。
6. **播放、缓存和历史：已实现。** 持久化记录只保存租户/账号可再查询的任务 ID 与重试参数；私有视频 Blob 只保存在会话内存缓存。`mediaCache.ts` 以账号 + 任务 ID 分区，合并并发 GET，限制 96 MiB，退出/换号清理并撤销 object URL。播放位置在同一应用会话内重挂载时恢复。
7. **历史成果的 AI 可读上下文：已实现，有明确边界。** 用户明确询问“这段视频/画面/成片”时，`generatedMediaContext.ts` 只读 GET 当前对话关联的已完成任务，抽取有上限的画面帧后再做配额预检。提示明确声明“仅分析采样画面，不含音频，未采样部分未知”，不把能播放误当作模型已读取。

## 原 17 项中本轮指定复核

- **2 并发：通过代码与自动测试复核。** 同账号最多 3 条 AI/视频任务，同对话最多 1 条，全局视频上限 6；并发同 ID 只有一次供应商调用，异参重放被拒绝。
- **3 下载反馈：通过代码与自动测试复核。** 优先使用文件选择器，只在字节真实写入后报“已保存”；浏览器锚点降级只报“已开始下载”，不虚假声称保存成功。
- **4 计时连续：通过代码复核。** 等待时长从服务端持久化 `job.createdAt` 计算，组件重挂载不会从 0 开始。
- **6 媒体缓存：通过代码与自动测试复核。** 见上述账号隔离、LRU/字节上限、进行中 GET 合并和登出清理。
- **17 工作区容量：通过代码与自动测试复核。** 工作区持久化上限为 8 MiB 且分块存储；视频提交只预留 64 KiB 元数据空间。超限时明确拒绝，不截断或静默删除旧对话。

## 安全和租户边界

- 视频设置、任务、参考图、配额、工具方案和管理员核对均使用已认证租户范围。
- 管理员对“结果未知”任务手工确认扣额时，用量记录会保留“失败/结果未验证”而不冒充生成成功；可观测性事件也会以 `AI_VIDEO_RECONCILED_CHARGE_UNVERIFIED` 区分于实际成功。
- 相同用户 ID、任务 ID、方案 ID 或参考图逻辑 ID 在两个租户内不会串读；非默认租户的供应商参考图能力 ID 由租户 + 逻辑 ID 派生。
- 输出视频只能通过当前账号已授权任务的规范供应商路径读取，服务端不信任供应商返回的任意下载 URL，响应不缓存。

## 验证边界与剩余项

- 本轮不调用付费视频生成，不调真实供应商，不部署。因此不声称 SD2.5 或其他模型的线上生成已验收。
- 本子任务未进行真实付费桌面验收；主任务另外使用本机隔离浏览器夹具，实际点击验证了真实组件的下拉、忙碌态与单次规划/提交。
- 内存媒体缓存故意不跨应用重启；重启后会凭持久化的任务 ID 重新受权 GET，而不把私有视频字节写入工作区。
- 生成视频的后续理解仅基于有上限采样帧，不含音频语义；这是显示在上下文中的产品边界。
