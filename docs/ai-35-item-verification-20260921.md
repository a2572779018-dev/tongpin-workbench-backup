## 本轮额外发现并修复

- 首次只配置 Harness 时，能力定价/搜索表单仍要求旧文字配置的问题。
- 换供应商/密钥后，旧异步模型查询不能覆盖新配置。
- 视频扣额但产物未确认，不能计为生成成功。
- 正常多分钟视频不能套用文本的超时告警阈值。
- 新会话进入视频追问时，要持久化参考图和参数，不能因切换会话 ID 丢失；草稿参数不保存任何可执行授权。

## 未安装的外部项目：具体阻碍

- [OpenSquilla 官方仓库](https://github.com/TokenRhythm/opensquilla)使用 Python 3.12+、LightGBM/ONNX 和模型权重（[依赖说明](https://github.com/TokenRhythm/opensquilla/blob/main/pyproject.toml)）。现有 Cloudflare JavaScript Worker 不能直接执行该原生运行时；需要独立锁版本的分类服务，或打包并验证跨平台 sidecar。只加名称、复制说明文件或词法规则不能算安装。
- [Dify 官方 Agent 插件](https://marketplace.dify.ai/plugin/langgenius/agent)依赖 Dify 的 Python 插件 session 模型/工具调用环境（[官方 manifest](https://github.com/langgenius/dify-official-plugins/blob/main/agent-strategies/cot_agent/manifest.yaml)）。真实接入需要独立 Dify 运行环境和同频授权代理，不能把插件直接作为 npm 依赖运行。完整平台的商业多租户许可还需独立确认，不能把插件许可等同整个平台许可。

本轮未创建新的托管服务、未购买基础设施、未把客户端密钥交给外部调度器。自研调度的可执行功能与上述两项原项目安装分开记录。
