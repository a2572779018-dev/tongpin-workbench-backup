# AI 进入前服务检查 · 2026-09-10

## 用户确认的规则

按实际连接、权限和额度检查，不按成员 IP 或日本/新加坡代理白名单拦截。不检测或更改系统代理，不上传地理位置。历史对话和草稿不因服务商故障被隐藏或删除。

## 实现

- Node 与 Cloudflare 共用 `/api/ai/availability?target=chat|image`。保留登录、成员/老板角色、账号绑定验证及 no-store 响应。
- 服务端先检查开通权限、配置和可用额度；图片模式另检查图片开关及单张额度。通过后，仅 GET 管理员保存的服务商 `/models`，不提交生成、不预留或扣除生成额度。
- 文字和独立图片接口分开检测，密钥只在服务端解密，不返回模型列表、上游原文或密钥。
- 同一目标/凭证的并发检查合并，完成后短缓存 15 秒；不缓存成员权限或额度。改密钥/地址立即重新检查，检查中变更配置则拒绝旧结果。真实生成失败会使该目标的连接缓存失效。
- 首次进入工作区或切换文字/图片目标时先禁用发送并显示检查状态；明确失败显示原因和“重新检测”。实际请求的明确服务故障按图片或当前快速/深度/搜索模式暂停发送；查询已提交请求结果仍可进行。
- 配置检查通过只标记“服务连接已检查”，不声称推理、特定模型、搜索或图片生成必然成功。检测接口 404/405/501、无法验证模型列表等标记“尚未验证”，允许尝试正常对话，避免误拦本来可用的生成接口。
- 单次上游检测 8 秒超时，前端等待上限 12 秒。卸载、账号或检测目标变化时取消旧请求，旧响应不能覆盖当前状态。检测不驱动高频全页面刷新。
- 当前预检针对文字和图片服务；H3 视频仍是独立服务流程，不能用文字连接检测结果声称视频可用。

## 验证结果

- `npm run build`：116 个测试文件、1137 项测试全部通过，类型检查、前端和 Node API 构建通过。
- `npm run typecheck:cloudflare` 通过；Cloudflare 部署 dry-run 通过（非发布）。
- 新增覆盖：无权限/无额度/未配置不请求上游；并发共享检查但不共享额度；密钥轮换；检测中配置/额度变化；图片与文字隔离；真实失败清除旧成功缓存；403 证据分类及敏感信息过滤；不支持检测、网络失败、缓存过期、路由权限及账号绑定。
- 浏览器隔离样例 `scripts/ai-availability-preview.html` 验证：进入自动检测、期间禁用发送、网关拒绝继续禁用、重新检测恢复、尚未验证提示、草稿和历史内容持续保留。使用模拟数据，生成次数始终为 0。
- React 与 Cloudflare 检查清单用于取消/过期响应保护、并发合并、有限缓存、权限隔离和无生成探测。

## 发布与能力边界

本次未部署生产后端、未推送安装包、未替换 Mac/Windows 0.1.39；不能据此称 Windows 服务商 403 已解决。发布时应先部署新 availability API 再推送对应客户端；旧后端不存在此接口时新版前端会提示管理员更新服务，不伪报检测成功。
