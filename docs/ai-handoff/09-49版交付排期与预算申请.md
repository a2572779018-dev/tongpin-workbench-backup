- **具体阻塞**：私有同频插件 0.1.1 两次安装失败（错误未定性）；`DifyEngineAdapter` 未被主聊天入口调用；没有公开回调许可与生产密钥。
- **可执行路线**：① 先在 Dify Cloud 沙盒只用 Workflow（已有内置工具跑通的经验），**不接主链**；② 同频侧只保留一个 Workflow 调用点，不保留第二套 Agent（避免"同频 Harness → LibreChat Agent → Dify Agent"三套引擎抢同一任务）；③ 需要 Dify 侧提供稳定的调用凭证与回调签名方式。
- **需要你批准**：Dify 生产密钥/回调地址；以及是否接受 **Dify 仅承担 Workflow**（不再保留 Agent 角色）这个定位。
- **对交付时间的影响**：不影响 A/B/C/D/E/F；若纳入 49 版，在凭证就绪后需额外 **2–3 天**。
- **约束**：无新条件**不重复安装**，**不自行延期**，**不假称完成**。

### #8 OpenSquilla（保持"受阻、未完成"）

- **具体阻塞**：官方运行时/权重/许可均未具备；现有 `server/ai/autoRouting.ts` 是自研快速路由，**不是** OpenSquilla。
