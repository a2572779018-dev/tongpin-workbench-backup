# 成员记忆学习循环（“越用越懂用户”，移植 Hermes Agent）

日期：2026-09-26。基线：`27ea8fd`。需求原话：“装 nousresearch/hermes-agent（越用越懂用户），github 上有开源”。

Jev：本任务无网络授权，**未调用**。真实供应商：**未调用**（全部测试使用本地 mock / Miniflare 出站拦截）。

## 结论：移植机制，不引入 Hermes 运行时

Hermes Agent（MIT，commit `d0288be5`）是 Python 智能体运行时：`MEMORY.md`/`USER.md` 两个有界文件 + `memory` 工具 + 回合结束后 fork 出的后台审阅代理。同频 AI 跑在 Cloudflare Durable Object（Express 为镜像），因此只移植机制：

| Hermes | 同频 |
| --- | --- |
| `MEMORY.md`（2,200 字符）/ `USER.md`（1,375 字符） | `memory` 工作笔记 1,000 字 / `user` 成员档案 600 字（中文等价换算见 `shared/aiMemory.ts`） |
| `memory_tool_store.py`：`§` 分隔、唯一子串 `old_text`、整条替换、批量按最终预算、超限报错并返回现有条目、拒绝清空 | `server/ai/memberMemoryStore.ts`（纯函数 + SQLite 仓库，修订号乐观并发） |
| 系统提示中的冻结快照 + 用量表头 | 每个对话首次请求时冻结（6 小时有效），`记忆（AI 的工作笔记）[67% — 670/1,000 字]`；成员修改立即失效重建 |
| `background_review.py` 回合后 fork 审阅 | 回复结算后写入审阅日志，宏任务启动一次快速档严格 JSON 调用；溢出时仅一次“合并”重试；失败由定时循环兜底 |
| 无人值守审阅不得删除（delete gate） | `remove` 仅在成员明确要求忘记、或为腾出空间时保留 |
| `threat_patterns.py`（strict） | `server/ai/memberMemorySafety.ts`，另加中文模式与凭据过滤 |
| `session_search`（FTS5） | **未实现**，见“后续” |

## 修改

- 新模块：`shared/aiMemory.ts`；`server/ai/aiMigrations.ts`（`ai_schema_migrations` 编号迁移，`member_memory` v1）；`memberMemoryStore/Safety/Prompt/Review/Service/Routes.ts`；`cloudflare/src/ai/memberMemoryRoutes.ts`。
- 数据表（迁移 v1）：`ai_member_memories`（每成员两组条目 JSON、修订号、学习开关）、`ai_member_memory_reviews`（审阅日志：状态、租约、预留/实扣同频点、增改删计数、供应商 Token）、`ai_member_memory_snapshots`（按对话冻结的提示块）。组织设置存 `ai_settings`（id `member_memory`）。
- 共享文件最小接入：`storage.ts` 调用迁移；`capabilities.ts` 在人设偏好后加入记忆块；`service.ts` 构造服务、两处人设读取改为附带记忆、成功回复后 `afterReply`、`runBackgroundMemoryCycle`、用量名称“记忆整理”；`shared/ai.ts` 新增用量类型 `memory` / `memory_conversion`；`app.ts`、`core.ts` 挂载路由与定时循环；`backgroundAgent.ts` 纳入记忆循环。
- 前端：侧栏「AI 对你的了解」面板（两类记忆用量条、增改删、“允许同频 AI 记住我”、清空全部记忆）；回复下方“已更新记忆”小标记（批量、有上限的轮询，仅计数）；AI 管理 → 生成与搜索 → 「记忆」卡片（启用、整理档位、每次更新折算、汇总数字）。
- `THIRD_PARTY_NOTICES.md` 记录 Hermes 来源、commit、许可证与改编文件。

## 隐私与计费

- 记忆仅成员本人可读写；管理员只有开关/档位/价格与组织汇总；老板与成员同权（只能看自己）；跨组织隔离。无账号删除流程（仅停用），停用账号的后台审阅会被跳过。
- 不保存：密码、密钥、令牌、验证码、私钥/助记词、证件/银行卡/账号号码（确定性过滤 + 审阅指令；送审前也会遮盖）；AI 回复、网页、附件内容只作上下文，审阅只记录成员本人陈述；疑似指令注入的条目被拒绝。
- 计费：组织默认关闭；启用后按管理员设定的每次折算（默认 100，可为 0）仅在记忆**实际更新**时扣除，调用前预留、失败/无变化释放；每成员每天最多 40 次，非明确请求至少间隔 30 秒；寒暄/很短对话不触发。
