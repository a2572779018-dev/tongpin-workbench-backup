# 统一电脑操作执行器（Cua Driver + Jev）

日期：2026-09-27。基线：`27ea8fd`。分支工作目录：`wt/computer`。

## 目标

用户发出需要操作电脑的指令（`@computer` 或普通对话中的直接指令，例如“让同频ai使用我的电脑微信客户端，给我的姐姐发一个中秋快乐”）→ 同频自动进入统一执行器：

指令 → 当前档位模型整理一次结构化任务（目标应用、逐字参数、完成标准、是否含发送等不可逆步骤）→ 主进程一次原生确认框（同时申请缺失的辅助功能/屏幕录制权限，并写明授权范围）→ 循环 {Cua Driver 读取界面 → 代码构造封闭候选集（≤32，含 reobserve/abstain/done）→ 服务端调用 Jev（TypeSafe System One，`jev-latest`）选一个候选 → 主进程核对授权与范围 → Cua Driver 执行 → 重新读取、验证} → 结果写回对话。

Jev（开发辅助决策）：本任务**未调用**真实 Jev/TypeSafe（未获本轮授权）；所有 Jev 调用均在测试中 mock。

## 修改

- 共享契约 `shared/computerAgent.ts`：任务结构校验（拒绝密码/验证码等敏感参数）、候选/观察/事实/决策类型、限制常量、自然语言电脑指令识别。
- 服务端：`server/ai/computerJev.ts`（最小 fetch 客户端，严格校验答案必须来自候选、概率与用量）、`computerSettings.ts`（“Jev 决策服务”密钥加密保存、价格、上限）、`computerExecutor.ts`（任务整理、逐步决策、预留/结算计费、`setComputerRunGuidanceHook` 钩子）、`computerTask.ts`、`computerRoutes.ts`（Express 与 Worker 共用路由表）、`computerExpress.ts`；Worker 出站白名单加入 `api.typesafe.ai`。
- Electron 主进程：`electron/computer-agent.cjs`（控制器）、`computer-agent-policy.cjs`（候选、授权、确认文案）、`computer-agent-host.cjs`（原生对话框、系统设置面板、Esc 全局停止、4 个 IPC）；`main.cjs`/`preload.cjs` 仅少量接线。
- 渲染端：`src/features/tongpin-ai/computerExecutor.ts`（执行循环）、`ComputerRunPanel.tsx` + `computer-run.css`（执行视图）、`AdminAiJevSettings.tsx`（AI 管理 → 生成与搜索）；`TongpinAIPage.tsx`/`ChatWorkspace.tsx` 小改接线；删除旧的逐动作确认面板（`ComputerUsePanel.tsx`、`computerUseTask.ts` 及其测试）。

## 安全与授权

- 主进程是权威：候选由主进程基于自己的观察构造并冻结，绑定观察编号（90 秒内、仅执行一次）；渲染端和服务端只传候选编号。
- 只输入任务里的逐字参数；从不向密码类输入框输入；终端、钥匙串、系统设置、脚本工具与同频自身不作为目标。
- 不可逆操作：只允许确认框中写明的那一次（例如“发送消息给「姐姐」：中秋快乐”），且发送前需证据（联系人可见、聊天确为本次打开、输入框恰为授权内容）；删除、付款、其它不可逆或证据不足时弹出“仅允许这一次/停止任务”的再次确认，拒绝即停止。
- 屏幕文字一律作为不可信数据，只进入观察，不改变任务、不授权任何动作。
- 结果不确定的动作从不自动重试；后台输入被拒或无效果时只提供独立的“前台”候选。

## 上限与计费

- 默认每次任务最多 30 步、6 分钟（管理员可调，上限 50 步/15 分钟），最低置信度 0.5；发送/删除/付款候选需 ≥0.7 且 Jev 的收件人/内容核对 ≥0.7。
- 任务整理：当前档位模型一次调用，按原有额度账本计费；每步 Jev 决策先按上限预留同频点，按 Jev 报告的输入/输出 Token 与管理员价格结算（崩溃后按预留保守结算）。

## Mac 手工验收（打包版）

1. AI 管理 → 服务与模型：给“深度”“Pro”勾选“电脑操作”；AI 管理 → 生成与搜索 → Jev 决策服务：填 TypeSafe 密钥、启用、点“检查连接”。
2. 成员账号、深度档位，微信已登录。对话里输入“让同频ai使用我的电脑微信客户端，给我的姐姐发一个中秋快乐”。
3. 预期：出现一次系统确认框（目标应用「微信」、只输入「姐姐」「中秋快乐」、不可逆操作“发送消息给「姐姐」：中秋快乐”、30 步/6 分钟、Esc 停止）；缺权限时系统提示并打开对应设置页，开启后自动继续。
4. 执行视图逐步显示“读取 → 候选 → Jev 选择（置信度）→ 授权检查 → 执行 → 验证”；微信中只给「姐姐」发送一次“中秋快乐”；对话里出现“已完成：已在「微信」给「姐姐」发送“中秋快乐”…”。
5. 反例：指令改为删除聊天记录或转账，应出现再次确认并可停止；执行中按 Esc 或点“停止”应立即停止；标准档位应提示切换到深度/Pro。
