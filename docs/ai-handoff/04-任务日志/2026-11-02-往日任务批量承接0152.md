## 根因与已改代码

- 原自动承接只查询前一天并限 09:30 以后，周末前遗留不可见；旧逐项/批量同步完成后自动跳今日，且把拒绝项也标成功。
- `shared/taskCarryover.ts`：按账号聚合同链最新有效叶节点，保留删除审计链接；完成/已承接/删除后不复活旧祖先，处理循环与孤立引用；稳定日期/ID 分页。日期相同时按更新时间/创建时间判新旧，最后才用 ID 稳定排序。
- Node/Cloudflare 新增只读 `/api/tasks/backlog`，保留旧同步协议，POST 重新校验权限、源日期和有效叶；Worker 插入与审计同事务，失败回滚、并发不重复。
- `TaskBacklog.tsx` 和专用 CSS：即时入口、按原日期分组、分页、全选当前已加载项、部分失败保留选择、明确的查看今日动作、键盘焦点/Esc；不自动改变历史任务日期。
- `MemberHome.tsx`：两种既有布局接入，不再自动跳页，状态查询完成前禁用“今”，后台刷新不吞失败提示；`taskCarryoverClient.ts` 按日期/100项分批，仅核对真实创建/跳过项，并绑定起始账号。
- 版本/发布文案为 0.1.52；依赖未变。CI 手动参数由误导性的 client_hotfix 改名 native_client_checks：Linux 完整后端/Worker质量门禁，Windows 实际客户端/Worker测试；默认流水线不变。上次 Windows Node 开发后端失败未被修复/关闭。
