# 引用角标（来源编号上标）

日期：2026-09-26。基线：`477871f`。关联：#17 / N-RICH-01 的“来源链接”。

## 目标与原则

答案正文内显示上标角标（如 “…今天晴 ¹²”），与下方编号来源列表一一对应；悬停/聚焦显示来源标题与域名，点击滚动并高亮对应来源（折叠时先展开）。角标只来自供应商真实 `url_citation`，偏移无法证明时整条回复不显示角标（来源列表不受影响），不猜测、不编造。

## 修改

- 服务端 `server/ai/citations.ts`（新）：逐段校验 `output_text` 注释偏移（越界/反向/非整数即整条放弃；含 emoji 时 UTF-16 与码点不一致，仅当注释区间恰为内联链接时判定单位，否则放弃）；段落 → `content`（拼接相等，或仅以空白分隔的 `output_text`）；`content` → 最终存储正文（唯一位置且两侧只有 `<analysis_summary>/<think>/<tool_request>` 过滤块或空白；中间被删改、JSON 外壳、应用改写一律放弃）。来源编号按 `sourceIdentity` 去重后的首现顺序，与客户端列表一致；上限 64 个角标。
- 流式：`providerStream.ts` 收集 `response.output_text.annotation.added`（及对应段文本），终态缺注释时并入；终态自带注释时以终态为准；终态只有 `output_text` 时按流式分段重建后再校验。
- `provider.ts`：被引用的页面可在普通 30 条来源之外补到 40 条，保证角标有来源可指。
- `service.ts`：仅对取自模型正文的回复计算 `citations` 并随结果持久化；工具方案/澄清/演示文稿不计算。V2 `commit-assistant` 一并写入。
- 共享 `shared/aiCitations.ts`（新）：`sourceIdentity`（由客户端迁入）、编号、单条校验；`AiCitation { n, sourceIndex, end }` 为可选字段（旧客户端忽略）。`workspace.ts` 校验字段、数量、来源存在与偏移在正文内。
- 客户端：`replyCitations.ts`（改编自 LibreChat `plugin.ts`）在已解析的 Markdown 树上插入角标节点，不改写原文：代码/公式/图片/链接内的偏移移到该结构之后，绝不嵌入链接；表格、转义、货币 `$` 转义均保持。模型自写的 `[n]`/`【n】` 仅在编号存在于来源列表时链接（`arr[1]`、行首参考列表、代码与链接内不链接）。`ReplyCitation.tsx`（改编自 `Citation.tsx`/`SourceHovercard.tsx`/`Context.tsx`）提供每条回复的上下文、角标按钮与奶油色黑描边悬浮卡（不加载远程 favicon）。`AiSourceLink.tsx` 来源列表编号并响应点击。流式期间只显示纯文本，终态结果到达后一次性加角标。
- `THIRD_PARTY_NOTICES.md` 补充 LibreChat 引用模块改编说明。
