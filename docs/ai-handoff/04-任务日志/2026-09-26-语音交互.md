# 2026-09-26 语音交互（任务 #6）

## 范围

同频 AI 聊天接入语音：输入框麦克风（录音 → 服务端转写 → 填入或直接发送）、回复「朗读」与停止、语音对话模式（转写自动发送 + 回复自动朗读）。移植 LibreChat v0.8.7 `9e74cc0` 的语音模块，来源与改动见 `THIRD_PARTY_NOTICES.md`「AI voice input and read-aloud」。未改「我的任务」「客户脉络图」。

## 实现

- 共享契约 `shared/aiVoice.ts`：单次录音 ≤ 60 秒、≤ 10 MB；外部朗读每次 ≤ 1000 字；计费函数（转写按秒向上取整折算每分钟单价，朗读按每千字向上取整）。
- 服务端 `server/ai/voice.ts`（Express 与 Worker 共用）：复用「服务与模型」里的服务连接，只有当前密钥已读取模型列表且包含所选模型时才调用（失败即关闭）。预留 → 调用 → 结算，写入 `ai_usage`（`kind: "voice"`），拒绝请求释放预留，不确定结果按预留保守计入；请求记录表 `ai_voice_requests` 惰性建表，同一 requestId 只转写一次（重放返回原文字）。音频不落盘、不记日志。
- 转写上传 `POST /api/ai/audio/transcriptions`（multipart），`server/ai/voiceAudio.ts` 先有界读取再用平台 `FormData` 解析（workerd 与 Node 相同）；按内容识别 WebM/Ogg/WAV/MP4 并读取真实时长（兼容 Chromium 未知长度 Cluster），计费取「声明时长」与「实测时长」较大者；MP3 与无法确认时长的大文件拒绝。Worker 入口仅为该路径放宽请求体上限（10 MB + 64 KB）。
- 朗读 `POST /api/ai/audio/speech`：仅在管理员选择「外部语音服务」时可用，返回音频；默认「系统语音」在成员电脑本地朗读、不计费。
- 管理：AI 管理 → 生成与搜索 →「语音」（`AdminAiVoiceSettings.tsx`），`GET/PUT /api/admin/ai/voice` 返回配置与成员端可用状态。
- 成员端：`src/features/tongpin-ai/voice/`。麦克风按钮独立于发送按钮；录音显示电平与计时，Esc 取消；设置弹层（语音对话模式、转写后自动发送、自动朗读、语速）按账号存 localStorage（读写均 try/catch）。朗读前去掉 Markdown、代码、公式、链接、引用角标；系统语音优先中文。
- Electron：`electron/media-permission-policy.cjs`。会话权限只放行主窗口本页面的纯音频 media 请求，其余权限保持 Electron 原默认；首次按麦克风时 macOS 调 `askForMediaAccess`（先查 `getMediaAccessStatus`），拒绝时给出「系统设置 → 隐私与安全性 → 麦克风」/「Windows 设置 → 隐私和安全性 → 麦克风」指引并可一键打开对应设置页。`package.json` `mac.extendInfo.NSMicrophoneUsageDescription`，两份 entitlements 加 `com.apple.security.device.audio-input`。
