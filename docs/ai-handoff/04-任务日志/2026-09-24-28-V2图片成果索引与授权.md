2026-09-24（Asia/Hong_Kong）。基线 `f730cdf`。仅改 AI 后台、测试和同目录交接；未改“我的任务”“客户脉络图”、WorkBuddy、生产配置或客户端。

## 实际修改

- V2 准备阶段从当前 V1 图片成果中建立 `租户 + 账号 + 对话 + assetId → artifactId` 候选索引，索引和分实体记录在同一 SQL 事务写入。旧数据中同一对话/图片对应多个成果时拒绝准备并保留 V1；删除图片不入索引，单成果扫描和总索引行数有界。
- 生成图片作为视频参考的后台入口按当前记录版本分派。V1 行为不变；V2 从一次 SQL 快照读取候选索引、指定会话和成果，不扫描整账号快照。随后校验实体哈希及字段、assistant 消息关联、成果会话/项目归属、非删除的图片引用、当前成员持有的图片字节和指纹；上传及付费提交前仍重新核验。缺失、歧义、墓碑或跨会话均拒绝，不回退 V1。
- 索引只负责定位，**不是来源凭证**。现有可保存的聊天状态只能证明图片当前关联该对话，不能证明图片最初确在该对话生成；后者需要服务端持有的生成请求/资产来源绑定，不在本包假称完成。
