# 工作包 18：视频同页滚动稳定挂载

2026-09-24（Asia/Hong_Kong）。基线 `3f29b60`，仅 AI 页面组件与隔离浏览器 fixture/脚本。未修改“我的任务”“客户脉络图”、WorkBuddy、服务端鉴权或生产发布。

## 缺口与修复

只读审计确认：视频回复的 `IntersectionObserver` 每次离开视口把 `visible` 改为 false，立即卸载 `<video>`、释放挂载，回来又重新 GET 原任务和完整视频；普通图片消息不会仅因滚动而卸载。新浏览器测试先红：滚出视口后原播放器 DOM 断开。

修复为“本次挂载首次进入视口后保持可见”的单向门闩。滚动期间保留播放器、进度与当前已授权的私有 Blob；真正切换对话导致组件重新挂载时，仍从未核验状态开始，重新 GET 任务与视频内容。没有凭暖缓存跳过新会话鉴权，也没有自动重复生成。

## 验证与边界

真实 React + Chrome、隔离假传输测试：同一挂载滚出/返回，播放器 DOM 不换、视频内容读取总计 1 次；切到 B 再回 C，旧节点卸载、新挂载内容读取总计 2 次。`videoChat`、`mediaAuthorization`、`mediaCache` 定向 33/33；Web/Cloudflare 类型检查与 Web 生产构建通过。测试未使用真实视频供应商或账号。

这只解决**同页滚动**的重复加载，不解决切换页面/重新打开时的完整下载，也未做有大量视频的内存压力验收；#6/#16 继续进行中。后续需服务端轻量授权探针、有限的媒体保留策略及 Mac/Windows 实机验证，不能把本包说成秒开全部完成。
