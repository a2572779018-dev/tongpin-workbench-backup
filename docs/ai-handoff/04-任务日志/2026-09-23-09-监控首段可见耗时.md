# 09 · 运行监控首段可见耗时

- 起点：`24f5fdf`；现有 AI 管理监控已存储按租户的请求结果、成功率、错误率、总耗时和站内阈值告警。
- 本里程碑仅补“从服务端接受请求到首段可见正文”的真实流式样本；非流式、纯工具方案和历史请求不补造数据。
- 范围：AI 运行监控数据结构、服务端写入/聚合、管理员页面及对应测试。不触及其他业务页面、发布、付费服务调用或外部通知渠道。
- 验收：流式正文产生一个样本；无流式正文时样本数为零并显示无数据；租户隔离和既有告警统计保持原状。

## 实际变更

- 服务端在持久化 `answer_delta` 后记录请求接受到首段可见正文的毫秒数；隐藏推理、公开摘要、工具 JSON 包装和仅有缓冲 JSON 的回复不产生该样本。这是用户可见输出等待时间，**不是**服务商内部 TTFT。
- `ai_observability_events.first_visible_ms` 可空。旧数据库增量加列，历史行仍为 `NULL`。管理员按租户、档位、服务和能力查看样本数与平均值；总平均只按有样本请求加权，页面没有样本时显示“—”。服务端不保存提示词或服务商正文到监控表。
- 监控仍是管理员打开页面后每 15 秒轮询的站内视图及阈值告警；**没有**声称后台实时推送或外部通知。
- `server/ai/service.ts` 的两处集成与公开摘要工作包共享同一文件，由总任务审查并作为 `81257a7` 单独提交；本工作包其他源码与日志为 `13d08e5`。
