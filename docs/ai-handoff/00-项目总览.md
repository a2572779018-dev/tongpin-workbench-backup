## 当前架构与入口

- 同频 Electron/React 客户端：`src/features/tongpin-ai/`，真实页面由 `src/pages/TongpinAIPage.tsx` 装配；`ChatMessageRow.tsx` 调用 `MarkdownReply.tsx`。
- Node 开发 API：`server/index.ts`、`server/routes/ai.ts`、`server/ai/service.ts`。Cloudflare 生产路径在 `cloudflare/src/`；AI 请求由 `cloudflare/src/ai/routes.ts` 分派，账号、额度、素材和账本仍归同频。
- 客户端聊天流、服务端提供者流及持久化必须按 [架构与开源复用](06-架构与开源复用.md) 中的实际调用链持续核验；不能把 Dify 沙盒或独立 Demo 当作同频主链路。
- 开发命令以仓库 `package.json` 为准：`npm run dev:api`、`npm run dev:web`、`npm run typecheck`、`npm run typecheck:cloudflare`、`npm test`、`npm run build:web`、`npm run build:api`。`cloudflare:deploy` 和 `release:activate:*` 会改变生产状态，不属于普通测试。
