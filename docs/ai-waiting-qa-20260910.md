# AI 等待流程修复验收 · 2026-09-10

## 问题与修复

- 原先 POST 返回 `AI_REQUEST_IN_PROGRESS` 时直接把助手消息标为 error；点击“重新获取回复”也只读取一次 pending 状态，没有持续恢复结果。
- 现在保留 thinking 状态，显示“正在等待 · 已用时 N 秒”。计时器单独在 ReplyWaiting 内更新，不逐秒更新聊天记录或持久化工作区。
- 首次发送只进行一次 POST；遇到处理中或网络结果不明后，每两秒 GET 同一 requestId，带当前账号隔离头。成功自动显示回复或图片成果。
- 请求发出后的“重新获取回复”仅 GET；只有因记录未保存、从未提交模型的请求才保留 POST 恢复入口。
- 停止等待、账号卸载会 abort；晚到结果不会覆盖新状态。真实拒绝、待核对等终态立即显示，不伪装为处理中。
- 每次等待有 180 秒总上限（含首次发送耗时），服务器的更早超时/终态优先。超时后保留原 requestId，可只读重新取回，不自动产生新任务。
