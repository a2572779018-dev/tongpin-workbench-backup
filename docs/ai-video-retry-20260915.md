# 视频失败后恢复编辑

## 已实现，尚未发布

- 已失败且预留已释放、或已完成的任务，显示“重新编辑并生成”。未结算/处理中/结果待核对不开放付费重试。
- 点击只恢复编辑器，保留原提示词、模型、时长、清晰度、画幅和参考图，用户再次确认后才创建新 requestId。
- 新任务将压缩参考图片与参数一起保存到当前对话成果数据中，沿用工作台容量检查、账号隔离和持久化；服务商临时图片地址过期不影响这份副本。
- 老任务由认证后的任务查询返回属于该任务的参考图 ID，客户端只读获取原图片；过期或缺失时明确报错，不静默改为文生视频。不会恢复其他成员任务。
- 草稿、附件或视频编辑器已有内容时不覆盖；恢复中的重复点击被锁住，切换账号/任务组件卸载会取消，不能误填到其他对话。
- 无新的视频生成请求，无额外付费实测。服务商 SD 2.0 返回 403 的权限/安全原因仍待服务商核查，这个补丁不声称修复 403。

## 验证

- 完整构建及 121 文件 / 1195 项测试通过；随后补充缺图副本不能覆盖原任务图片数量的测试。
- 覆盖持久化恢复、旧图按顺序恢复、过期失败、待核对/预留拒绝、非法图片、只读恢复、新生成使用新编号、跨账号不能读取图 ID。
- 安装的 0.1.44 尚不包含此补丁；未修改更新清单。
