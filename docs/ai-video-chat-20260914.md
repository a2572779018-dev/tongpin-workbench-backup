# 对话内视频生成验收（2026-09-14）

状态：本地实现与验证完成，尚未部署、推送或替换安装包；当前发布版本仍为 0.1.41。

## 修改

- 视频生成入口改为聊天输入区内的参数面板，不再打开独立生成弹窗。
- 明确的视频生成请求会进入视频模式，确认后才提交；脚本、提示词等讨论不自动生成。
- 生成进度、失败信息与完成后的原生视频播放器作为 AI 回复显示。
- 先保存关联对话的任务消息，再提交生成；查询和恢复任务不重新提交生成请求。
- 可以把已有视频任务加入当前对话，不重新生成。
- 为原生模态对话框和视频控件恢复系统光标，避免顶层弹窗遮住自定义光标后鼠标不可见。

## 验证

- 完整构建通过：119 个测试文件、1167 项测试，含类型检查、前端与 API 构建。
- 隔离页面使用实际聊天组件、持久化流程与合成 MP4，验证进入视频模式、生成进度、内嵌播放、刷新恢复和已有任务导入。
- 播放按钮切换为暂停，确认视频实际可播放。
- 刷新与导入已有任务后，隔离接口的生成提交计数仍为 1。
- 隔离测试没有调用付费服务商，不代表本次重新验证了真实 H3 生成；没有消耗用户余额。

隔离验收入口：`scripts/video-chat-preview.html`。该页面及合成视频是测试资源，不是生产 API 或真实生成结果。
